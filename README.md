# Evidencija dužnika / Debtor Registry

## Srpski

Aplikacija služi optici za jednostavno vođenje evidencije dužnika i njihovih zaduženja. Čuva osnovne podatke o dužniku, broj rata i uplate, prikazuje dugove po godinama i automatski računa ukupno uplaćeno i preostali dug.

## English

This application helps an optical shop manage debtors and their debts. It stores basic debtor details, installment plans and payments, groups debts by year, and automatically calculates total payments and outstanding balances.
